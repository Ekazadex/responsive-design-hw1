# Responsive Stylesheet with Media Queries

A responsive web page implementing viewport-based layouts across mobile, tablet, and desktop screens. Developed for the **Advanced Styling with Responsive Design** course by the University of Michigan on Coursera.

## Live Demo

- **Live Site:** [View Responsive Gallery on GitHub Pages](https://ekazadex.github.io/responsive-design-hw1/)
- **Repository:** [GitHub Repository](https://github.com/Ekazadex/responsive-design-hw1)

## Implementation Details

- **Mobile View (Default):** Single-column stacked cards layout.
- **Tablet View (`min-width: 772px`):** Dual-column layout using `width: 45%`, `display: inline-block`, and `vertical-align: top`, with images constrained to `max-height: 30vh`.
- **Large Screen View (`min-width: 998px`):** Three-column layout using `width: 30%`.

## Tech Stack

- HTML5
- CSS3 (Fluid measurements and CSS Media Queries)
